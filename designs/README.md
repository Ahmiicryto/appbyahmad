# Screen designs

Source files of the design canvas: 14 screens, each in a male (Black + Green) and a
female (Black + Maroon) version, plus the tab bar. `Female-*.dc.html` files reuse the
main screens with the female theme. `canvas.json` is the canvas layout.

The live, clickable canvas is the private artifact this was published from:
https://claude.ai/artifact/QnfaJdoSg5DGBUsUPKUy3r (share it from its Share menu).
